# Список присутствующих

Небольшой сайт без сервера: отмечайте людей галочкой или крестиком, а внизу автоматически формируется текст.

## Как добавить свой список

Откройте `data.js` и замените содержимое массива `people`:

```js
const people = [
  'Иван Иванов',
  'Анна Петрова'
];
```

Отметки сохраняются только в браузере на этом устройстве через `localStorage`. Кнопка «Сбросить» очищает все отметки.
